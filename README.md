# Phonic Privacy Policy

This repository hosts the public privacy policy for **Phonic**, a minimal iOS dictation app.

The live page is at **https://parzival74.github.io/phonic-privacy/**.

That URL is the one referenced in Phonic's App Store Connect listing under "Privacy Policy URL", and is shown to users from inside the app's About section.

The source content is in [`index.md`](index.md). It's deployed automatically by GitHub Pages using the `jekyll-theme-minimal` theme.

The Phonic app itself lives in a separate (private) repository.
